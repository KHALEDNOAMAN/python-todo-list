# 📋 To-Do List Manager (CLI)

A lightweight, command-line task management tool that helps you organize your daily tasks with priority levels and persistent CSV storage.

## ✨ Features

* **Add tasks** with priority levels: High, Medium, Low
* **Delete tasks** by name
* **View all tasks** in a clean, readable list
* **Persistent storage** – save your task list to a CSV file
* **Load from CSV** – restore your tasks anytime; duplicate names are automatically skipped

## 🚀 Getting Started

### Prerequisites

* Python 3.x

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MahdiKordian/python-todo-list.git
   cd python-todo-list
   ```

2. Run the application:

   ```bash
   python todo_list.py
   ```

### Usage

After running the program, follow the interactive menu:

* Choose option `1` to add a new task
* Choose option `2` to delete a task
* Choose option `3` to view all tasks
* Choose option `4` to save your tasks to `Historical data.csv`
* Choose option `5` to load tasks from the CSV file
* Choose option `6` to exit

## 🛠 Tech Stack
